PATCH WEBP — HERO + NOSSO PRIMEIRO BEIJO

Objetivo:
- reduzir os 5 PNGs pesados;
- preservar transparência das ilustrações;
- manter o loading curto;
- carregar Hero + frame inicial do beijo antes de abrir;
- aquecer as outras poses em segundo plano;
- impedir Trabalho de disparar requests no boot.

Uso:
1. Extraia este ZIP NA RAIZ do sitejuju.
2. Rode:
   powershell -ExecutionPolicy Bypass -File .\APLICAR_OTIMIZACAO_WEBP.ps1
3. O script:
   - cria backup fora do repositório, na pasta TEMP;
   - converte os 5 PNGs para WebP;
   - aplica os caminhos .webp;
   - remove os PNGs antigos de public/assets;
   - executa pnpm build.
4. Teste:
   pnpm dev
5. Se estiver correto:
   git add -A
   git commit -m "optimize first kiss assets to webp"
   git push

Qualidade:
- fundo da festa: WebP q82
- ilustrações com transparência: WebP q84, alphaQuality 92
